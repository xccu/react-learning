# xlsx（SheetJS）详解：Excel 导入导出

---

## xlsx（SheetJS）的定义

xlsx（SheetJS）是前端最流行的表格文件处理库，支持在浏览器中读取与生成 Excel（`.xlsx`、`.xls`）以及 CSV 等格式文件。它无需任何服务器支持，即可完成工作表数据的解析、转换与生成，是 React 应用中实现工时记录导入导出功能的常用方案。

**核心特点：**
- 纯前端解析与生成 Excel 文件，无需安装 Office 或依赖后端服务
- 支持 `.xlsx`、`.xls`、`.csv` 等多种格式，提供二维数组与 JSON 两种数据转换方式
- 体积可控、API 简洁，适合在浏览器端处理中小规模表格数据

**官方文档链接：**
- [SheetJS 官方文档](https://docs.sheetjs.com)

## xlsx（SheetJS）基本用法

### 1. 导出 Excel：将工时记录写入工作簿并下载

```ts
import * as XLSX from 'xlsx';

const records = [
  ['工号', '姓名', '日期', '工时', '备注'],
  ['A001', '张三', '2026-08-01', 8, '前端开发'],
  ['A002', '李四', '2026-08-01', 7.5, '需求评审'],
  ['A003', '王五', '2026-08-02', 8, '后端联调'],
];

function exportWorkHours() {
  const worksheet = XLSX.utils.aoa_to_sheet(records);
  const workbook = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(workbook, worksheet, '工时记录');
  XLSX.writeFile(workbook, '工时记录表.xlsx');
}
```

- **二维数组**：`records` 第一行是中文表头，后续每一行是一条工时记录
- **转工作表**：`XLSX.utils.aoa_to_sheet(records)` 将二维数组转换为工作表对象
- **创建工作簿**：`XLSX.utils.book_new()` 创建空工作簿
- **放入工作表**：`book_append_sheet(workbook, worksheet, '工时记录')` 将工作表加入工作簿并命名
- **触发下载**：`XLSX.writeFile(workbook, '工时记录表.xlsx')` 生成文件并触发浏览器下载

### 2. 导出复杂数据：从接口 JSON 生成工作表

```ts
import * as XLSX from 'xlsx';

interface WorkHour {
  employeeNo: string;
  employeeName: string;
  date: string;
  hours: number;
  remark: string;
}

function exportFromApi(data: WorkHour[]) {
  const header = [['工号', '姓名', '日期', '工时', '备注']];
  const rows = data.map((item) => [
    item.employeeNo,
    item.employeeName,
    item.date,
    item.hours,
    item.remark,
  ]);

  const worksheet = XLSX.utils.aoa_to_sheet([...header, ...rows]);
  worksheet['!cols'] = [{ wch: 10 }, { wch: 10 }, { wch: 12 }, { wch: 8 }, { wch: 20 }];
  const workbook = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(workbook, worksheet, '工时记录');
  XLSX.writeFile(workbook, '工时记录表.xlsx');
}
```

- **接口数据**：`data` 是接口返回的工时记录数组，每条记录是一个对象
- **数据映射**：`data.map(...)` 将对象数组转换为二维数组行，保证列顺序与表头一致
- **合并表头**：`[...header, ...rows]` 用展开运算符把表头与数据行合并
- **设置列宽**：`worksheet['!cols']` 可选配置各列宽度（`wch` 单位为字符），提升可读性

### 3. 导入 Excel：解析本地文件为工时记录

```ts
import * as XLSX from 'xlsx';

async function importWorkHours(file: File) {
  if (!file) {
    alert('请先选择 Excel 文件');
    return;
  }
  if (!/\.(xlsx|xls)$/i.test(file.name)) {
    alert('仅支持 .xlsx 或 .xls 格式文件');
    return;
  }

  const buffer = await file.arrayBuffer();
  const workbook = XLSX.read(buffer, { type: 'array' });
  const sheet = workbook.Sheets[workbook.SheetNames[0]];
  const rows: any[][] = XLSX.utils.sheet_to_json(sheet, { header: 1 });

  rows.slice(1).forEach((row) => {
    console.log(`导入工时记录：${row[1]} ${row[2]} 共 ${row[3]} 小时`);
  });
}
```

- **判空校验**：`if (!file)` 读取前先判断文件是否存在，避免空文件报错
- **格式限制**：`/\.(xlsx|xls)$/i.test(file.name)` 用正则校验文件扩展名
- **读取二进制**：`file.arrayBuffer()` 是浏览器 FileReader 接口的现代替代，将文件读为 ArrayBuffer
- **解析工作簿**：`XLSX.read(buffer, { type: 'array' })` 将二进制数据解析为工作簿对象
- **获取工作表**：`workbook.Sheets[workbook.SheetNames[0]]` 取第一个工作表
- **表格转数组**：`sheet_to_json(sheet, { header: 1 })` 将表格转为二维数组，`header: 1` 表示每行是一个数组
- **跳过表头**：`rows.slice(1)` 去掉首行中文表头，逐条处理数据行

### 4. 导入后写入接口：逐条提交并反馈结果

```ts
import * as XLSX from 'xlsx';

async function importAndSubmit(file: File) {
  if (!file) return;

  const buffer = await file.arrayBuffer();
  const workbook = XLSX.read(buffer, { type: 'array' });
  const sheet = workbook.Sheets[workbook.SheetNames[0]];
  const rows: any[][] = XLSX.utils.sheet_to_json(sheet, { header: 1 });

  const success: string[] = [];
  const failed: string[] = [];
  for (const row of rows.slice(1)) {
    const payload = {
      employeeNo: row[0],
      employeeName: row[1],
      date: row[2],
      hours: row[3],
      remark: row[4] ?? '',
    };
    try {
      await submitWorkHour(payload);
      success.push(String(row[1]));
    } catch (error) {
      failed.push(String(row[1]));
    }
  }
  alert(`导入完成：成功 ${success.length} 条，失败 ${failed.length} 条`);
}
```

- **逐条提交**：`for ... of` 循环逐条读取数据并调用 `submitWorkHour` 写入接口
- **字段映射**：`payload` 将数组下标映射为接口字段，`row[4] ?? ''` 处理备注为空的情况
- **结果统计**：`success` 与 `failed` 数组分别记录成功与失败的数据，便于反馈
- **汇总反馈**：`alert(...)` 用模板字符串汇总导入条数与成功失败数量

## 常见陷阱与最佳实践

### 1. 读取文件前未判空

```ts
// 错误：文件为空时直接读取，抛错中断流程
async function badImport() {
  const buffer = await file.arrayBuffer();
  const workbook = XLSX.read(buffer, { type: 'array' });
}

// 正确：先判空再读取，并给出用户提示
async function goodImport(file: File | null) {
  if (!file) {
    alert('请先选择 Excel 文件');
    return;
  }
  const buffer = await file.arrayBuffer();
  const workbook = XLSX.read(buffer, { type: 'array' });
}
```

- **判空时机**：`if (!file)` 必须在调用 `arrayBuffer()` 之前判断
- **提示用户**：判空失败时 `alert(...)` 明确告知用户操作问题

### 2. 文件类型限制

```ts
// 错误：仅设置 accept，用户仍可选择其他类型文件
<input type="file" accept=".xlsx" onChange={handleChange} />

// 正确：accept 之外，再用正则校验文件名
const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file && !/\.(xlsx|xls)$/i.test(file.name)) {
    alert('仅支持 .xlsx 或 .xls 格式文件');
    return;
  }
};
```

- **accept 属性**：`accept=".xlsx"` 是选择器提示，并非强制限制
- **二次校验**：`/\.(xlsx|xls)$/i.test(file.name)` 在代码中再次校验，杜绝绕过

### 3. 中文列名对应

```ts
// 错误：直接用表头当字段名，列顺序变化时数据错乱
const rows = XLSX.utils.sheet_to_json(sheet);
rows.forEach((row: any) => console.log(row['工号']));

// 正确：使用 header: 1 按索引读取，列顺序可控
const rows: any[][] = XLSX.utils.sheet_to_json(sheet, { header: 1 });
rows.slice(1).forEach((row) => {
  console.log(`工号 ${row[0]}，姓名 ${row[1]}，工时 ${row[3]}`);
});
```

- **中文表头问题**：`sheet_to_json(sheet)` 默认把表头当键名，中文表头变化会破坏结构
- **索引读取**：`{ header: 1 }` 返回二维数组，用固定下标访问，列顺序变更影响小

### 4. 大数据逐条导入的性能

```ts
// 错误：全量一次性提交，请求量大且无进度反馈
const result = await Promise.all(rows.slice(1).map((row) => submitWorkHour(row)));

// 正确：分批提交并更新进度，避免阻塞页面
const BATCH_SIZE = 100;
for (let i = 0; i < dataRows.length; i += BATCH_SIZE) {
  const batch = dataRows.slice(i, i + BATCH_SIZE);
  await Promise.all(batch.map((row) => submitWorkHour(row)));
  setProgress(Math.min(100, Math.round(((i + BATCH_SIZE) / dataRows.length) * 100)));
}
```

- **分批处理**：`for` 循环按 `BATCH_SIZE` 切片，分批调用接口，降低单次请求压力
- **进度反馈**：`setProgress(...)` 每批完成后更新进度条，提升长任务体验
- **并发控制**：`Promise.all(batch.map(...))` 批次内并发、批次间串行，平衡速度与稳定性

### 5. 日期与数字格式

```ts
// 错误：日期单元格被解析为时间戳，数字保留过长小数
const rawDate = row[2];              // 可能是 45375 这样的时间戳
const rawHours = row[3];             // 可能是 7.9999999

// 正确：设置单元格格式，或统一转字符串再处理
import * as XLSX from 'xlsx';
const worksheet = XLSX.utils.aoa_to_sheet(records);
worksheet['!cols'] = [{ wch: 12 }, { wch: 12 }, { wch: 12 }, { wch: 8 }, { wch: 20 }];

const dateText = XLSX.SSF.format('yyyy-mm-dd', row[2]);
const hoursText = Number(row[3]).toFixed(1);
```

- **时间戳问题**：Excel 日期存储为序列号，导入后需用 `SSF.format('yyyy-mm-dd', ...)` 还原
- **浮点误差**：工时等数字可能带浮点误差，导出前用 `toFixed(1)` 规范小数位
- **统一格式**：导出时在 `!cols` 上设置列宽，配合数据格式化避免单元格自动换型

### 6. 最佳实践

1. **文件读取前先判空并校验类型**，避免空文件或错误格式导致流程中断
2. **统一使用中文表头加索引读取**，导出用 `aoa_to_sheet`、导入用 `sheet_to_json(..., { header: 1 })`
3. **导入数据逐条或分批写入接口**，并统计成功失败数量反馈用户
4. **处理日期与数字格式**，使用 `SSF.format` 与 `toFixed` 避免时间戳与浮点误差
5. **大数据量采用分批提交并显示进度**，防止页面卡顿
6. **将导出导入逻辑封装为独立工具函数**，参数化数据源与文件名，便于复用和测试

## 总结

xlsx（SheetJS）是 React 应用处理 Excel 文件的核心工具：

- **导出**：`aoa_to_sheet` 转工作表、`book_new` 建工作簿、`book_append_sheet` 放入工作表、`writeFile` 触发下载
- **导入**：`file.arrayBuffer()` 读取本地文件、`XLSX.read` 解析二进制、`sheet_to_json` 转二维数组
- **格式**：以二维数组为桥梁，配合中文表头保证列顺序可控
- **性能**：导入写入接口时逐条或分批处理，并反馈成功失败统计
- **健壮性**：文件判空、类型校验、日期与数字格式化是避免线上问题的关键
