# React Hook Form 详解：表单管理与验证

---

## React Hook Form 的定义

React Hook Form 是一个基于**非受控组件**的高性能 React 表单库。它通过 ref 直接读取 DOM 值，避免每次输入都触发组件重渲染，从而大幅提升复杂表单的性能与响应速度。

**核心特点：**
- 基于非受控组件，减少不必要的重渲染，性能优于受控组件方案
- 提供 `useForm` Hook 与 `register` 方法，几行代码即可完成字段注册与校验
- 内置验证规则与错误信息收集，可无缝集成 Ant Design、MUI 等 UI 组件库

## React Hook Form 基本用法

### 1. 表单 Hook 与字段注册

```tsx
import { useForm } from 'react-hook-form';

interface WorkLogForm {
  projectName: string;
  description: string;
  hours: number;
}

function WorkLogForm() {
  const { register, handleSubmit } = useForm<WorkLogForm>();

  const onSubmit = (data: WorkLogForm) => {
    console.log('提交的工时数据：', data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('projectName')} placeholder="项目名称" />
      <textarea {...register('description')} placeholder="工作描述" />
      <input {...register('hours')} type="number" placeholder="工时数" />
      <button type="submit">提交</button>
    </form>
  );
}
```

- **useForm Hook**：`useForm<WorkLogForm>()` 创建表单实例，泛型传入表单数据类型
- **字段注册**：`{...register('projectName')}` 将 ref 与 name 注册到表单，非受控方式绑定字段
- **提交处理器**：`handleSubmit(onSubmit)` 校验通过后才执行 `onSubmit`，参数是校验后的表单数据
- **无需受控 state**：不需要为每个输入框写 `value` 与 `onChange`，字段值由 ref 读取

### 2. 表单验证

```tsx
import { useForm } from 'react-hook-form';

interface WorkLogForm {
  projectName: string;
  description: string;
  hours: number;
}

function WorkLogForm() {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm<WorkLogForm>();

  const onSubmit = (data: WorkLogForm) => {
    console.log('提交的工时数据：', data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)} noValidate>
      <input
        {...register('projectName', {
          required: '项目名称不能为空',
          maxLength: { value: 20, message: '项目名称不能超过 20 个字符' },
        })}
        placeholder="项目名称"
      />
      {errors.projectName && <p style={{ color: 'red' }}>{errors.projectName.message}</p>}

      <input
        {...register('hours', {
          required: '工时数必填',
          min: { value: 0.5, message: '工时数不能小于 0.5' },
          max: { value: 24, message: '工时数不能大于 24' },
          validate: (value) =>
            Number.isInteger(value * 2) || '工时数必须是 0.5 的倍数',
        })}
        type="number"
        placeholder="工时数"
      />
      {errors.hours && <p style={{ color: 'red' }}>{errors.hours.message}</p>}

      <button type="submit">提交</button>
    </form>
  );
}
```

- **必填校验**：`required: '项目名称不能为空'` 校验规则的值就是错误提示文案
- **长度与范围**：`maxLength`、`min`、`max` 等内置规则，配合 `value` 与 `message` 使用
- **自定义校验**：`validate: (value) => ...` 函数返回 true 表示通过，返回字符串表示错误信息
- **错误信息取值**：`errors.projectName.message` 从 `formState.errors` 中读取字段错误文案
- **noValidate**：表单上添加 `noValidate`，关闭浏览器原生校验提示，统一使用 React Hook Form 校验

### 3. 新增与编辑复用

```tsx
import { useEffect } from 'react';
import { useForm } from 'react-hook-form';

interface WorkLogForm {
  projectName: string;
  description: string;
  hours: number;
}

interface Props {
  defaultValues?: WorkLogForm;
  onSubmit: (data: WorkLogForm) => void;
}

function WorkLogForm({ defaultValues, onSubmit }: Props) {
  const { register, handleSubmit, reset } = useForm<WorkLogForm>();

  useEffect(() => {
    if (defaultValues) {
      reset(defaultValues);
    }
  }, [defaultValues, reset]);

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('projectName')} placeholder="项目名称" />
      <textarea {...register('description')} placeholder="工作描述" />
      <input {...register('hours')} type="number" placeholder="工时数" />
      <button type="submit">保存</button>
      <button type="button" onClick={() => reset()}>
        重置
      </button>
    </form>
  );
}
```

- **默认值预填**：`reset(defaultValues)` 将编辑数据写入表单，新增/编辑共用同一组件
- **重置表单**：`reset()` 不带参数时清空所有字段，适合"新增"场景提交后使用
- **依赖监听**：`useEffect` 依赖 `defaultValues`，编辑数据变化时重新填充
- **onSubmit 复用**：提交逻辑由父组件传入，新增与编辑场景共用一套校验

### 4. 提交状态

```tsx
import { useForm } from 'react-hook-form';

interface WorkLogForm {
  projectName: string;
  description: string;
  hours: number;
}

function WorkLogForm() {
  const {
    register,
    handleSubmit,
    reset,
    formState: { isSubmitting, errors },
  } = useForm<WorkLogForm>();

  const onSubmit = async (data: WorkLogForm) => {
    await saveWorkLog(data); // 调用接口保存工时数据
    reset();
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('projectName', { required: '项目名称不能为空' })} placeholder="项目名称" />
      <input {...register('hours', { required: '工时数必填' })} type="number" placeholder="工时数" />
      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? '提交中...' : '提交'}
      </button>
    </form>
  );
}
```

- **提交中状态**：`formState.isSubmitting` 在 `onSubmit` 返回的 Promise 完成前为 true
- **禁用按钮**：`disabled={isSubmitting}` 提交期间禁用按钮，防止重复提交
- **加载提示**：`{isSubmitting ? '提交中...' : '提交'}` 根据状态切换按钮文案
- **提交后重置**：接口调用完成后调用 `reset()`，清空表单便于下次录入

## 常见陷阱与最佳实践

### 1. 注册后手写受控 value/onChange 导致冲突

```tsx
// 错误：register 与手动 value 同时使用，输入框无法输入
<input {...register('projectName')} value={projectName} onChange={handleChange} />

// 正确：只使用 register 注册，由 React Hook Form 管理值
<input {...register('projectName')} />

// 正确：必须受控时使用 Controller，而非手动绑定
<Controller
  name="projectName"
  control={control}
  render={({ field }) => <input {...field} />}
/>
```

- **非受控绑定**：`register` 通过 ref 读取值，添加受控 `value`/`onChange` 会造成值被覆盖无法输入
- **Controller 适配**：与日期选择器、下拉框等只支持受控的组件集成时，使用 `Controller` 包装

### 2. 默认值变化不生效

```tsx
// 错误：defaultValues 只在组件首次挂载时生效，异步数据到来后不会更新
const { register } = useForm({ defaultValues: { projectName: '' } });
useEffect(() => {
  // 异步获取数据后，界面不会自动填充
  setProjectName(data.projectName);
}, [data]);

// 正确：使用 reset 将异步数据写入表单
const { register, reset } = useForm({ defaultValues: { projectName: '' } });
useEffect(() => {
  if (data) {
    reset({ projectName: data.projectName });
  }
}, [data, reset]);
```

- **defaultValues 时机**：`useForm` 的 `defaultValues` 仅在首次挂载时生效
- **异步预填**：异步获取的数据必须通过 `reset()` 写入，直接改状态不会触发更新

### 3. 错误信息取值方式

```tsx
// 错误：把 errors 直接传给组件，取不到具体字段错误
{errors && <span>有错误</span>}

// 正确：按字段名取值
{errors.projectName && <span>{errors.projectName.message}</span>}

// 推荐：封装通用错误文本组件
function FieldError({ error }: { error?: { message?: string } }) {
  return error?.message ? <span style={{ color: 'red' }}>{error.message}</span> : null;
}
```

- **按字段取值**：`errors.projectName.message` 每个字段的提示文案相互独立
- **空值安全**：封装组件时使用可选链 `error?.message`，避免字段无错误时渲染出错

### 4. 与 UI 组件库集成

```tsx
import { Controller, useForm } from 'react-hook-form';
import { Input, Form } from 'antd';

function WorkLogForm() {
  const { control, handleSubmit, formState: { errors } } = useForm();

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <Controller
        name="projectName"
        control={control}
        rules={{ required: '项目名称不能为空' }}
        render={({ field }) => (
          <Form.Item
            label="项目名称"
            validateStatus={errors.projectName ? 'error' : undefined}
            help={errors.projectName?.message}
          >
            <Input {...field} placeholder="请输入项目名称" />
          </Form.Item>
        )}
      />
      <button type="submit">提交</button>
    </form>
  );
}
```

- **Controller 桥接**：通过 `Controller` 的 `render` 把 `field` 展开到组件库输入组件
- **校验透传**：校验规则写在 `rules` 中，错误信息由 `errors` 传入组件库的 `help` 与 `validateStatus`

### 5. 最佳实践

1. **优先使用非受控的 `register`**，仅在与只支持受控的 UI 组件集成时使用 `Controller`
2. **校验规则使用对象形式**，并为每个规则配置 `message`，便于直接展示错误文案
3. **异步回填数据用 `reset()`**，不要依赖 `defaultValues` 或手动 setState 同步表单
4. **利用 `formState.isSubmitting` 禁用提交按钮**，防止用户重复提交
5. **表单提交逻辑保持纯函数**，`onSubmit` 只负责收集数据，接口调用交给外部或异步处理
6. **为表单数据定义 TypeScript 类型**，让 `useForm<T>` 提供字段级类型提示与校验

## 总结

React Hook Form 基于非受控组件思想，为 React 表单提供了高性能的解决方案：

- **性能**：基于 ref 直接读写 DOM，减少重渲染，适合大型复杂表单
- **易用**：`register` + `handleSubmit` 几行代码完成字段注册、校验与提交
- **验证**：内置必填、范围、自定义规则，错误信息逐字段展示
- **复用**：通过 `reset` 支持新增与编辑共用组件，异步数据预填
- **集成**：`Controller` 桥接受控组件，无缝对接 Ant Design 等 UI 组件库
