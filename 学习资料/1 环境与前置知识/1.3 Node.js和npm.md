# Node.js 和 npm 详解：环境配置、包管理与脚本命令

---

## Node.js 的定义

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境，允许在服务器端运行 JavaScript。它是 React 开发环境的基础。

**核心特点：**
- 非阻塞 I/O 模型，适合高并发场景
- 拥有全球最大的包生态系统（npm）
- React 项目的构建和开发依赖 Node.js

**官方文档链接：**
- [Node.js 官方文档](https://nodejs.org/en/docs/)
- [npm 官方文档](https://docs.npmjs.com/)

## Node.js 基础

### 1. 安装与版本管理

```bash
# 查看 Node.js 版本
node -v

# 查看 npm 版本
npm -v

# 推荐使用 nvm 管理 Node 版本
# Windows: nvm-windows
# Mac/Linux: nvm

# 安装指定版本
nvm install 18
nvm use 18

# 设置默认版本
nvm alias default 18
```

### 2. 运行 JavaScript 文件

```javascript
// hello.js
console.log('Hello, Node.js!');

// 运行
node hello.js
```

### 3. Node.js 核心模块

```javascript
// 文件系统
const fs = require('fs');
const data = fs.readFileSync('file.txt', 'utf-8');
fs.writeFileSync('output.txt', 'Hello');

// 路径处理
const path = require('path');
const fullPath = path.join(__dirname, 'file.txt');
const fileName = path.basename(fullPath);

// 模块系统
const myModule = require('./myModule');
module.exports = myModule;
```

## npm 基础

### 1. 初始化项目

```bash
# 初始化 package.json
npm init

# 交互式初始化
npm init -y

# package.json 结构
{
  "name": "my-react-app",
  "version": "1.0.0",
  "description": "My React application",
  "main": "index.js",
  "scripts": {
    "start": "react-scripts start",
    "build": "react-scripts build",
    "test": "react-scripts test"
  },
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0"
  },
  "devDependencies": {
    "typescript": "^5.0.0"
  }
}
```

### 2. 安装依赖

```bash
# 安装生产依赖
npm install react react-dom
npm i react react-dom

# 安装开发依赖
npm install --save-dev typescript eslint
npm i -D typescript eslint

# 安装指定版本
npm install react@17.0.2

# 全局安装
npm install -g create-react-app
npm install -g typescript
```

### 3. 依赖类型

| 类型 | 说明 | 安装命令 | 保存位置 |
|------|------|---------|---------|
| 生产依赖 | 运行时必需 | `npm install xxx` | dependencies |
| 开发依赖 | 开发工具 | `npm install -D xxx` | devDependencies |
| 全局依赖 | 系统级工具 | `npm install -g xxx` | 全局目录 |

## npm 脚本命令

### 1. 定义脚本

```json
{
  "scripts": {
    "start": "react-scripts start",
    "build": "react-scripts build",
    "test": "react-scripts test",
    "eject": "react-scripts eject",
    "lint": "eslint src/",
    "format": "prettier --write src/"
  }
}
```

### 2. 运行脚本

```bash
# 运行脚本
npm run start
npm run build
npm run lint

# 组合命令
npm run lint && npm run format

# 使用 cross-env 设置环境变量（跨平台）
"scripts": {
  "start": "cross-env PORT=3001 react-scripts start"
}
```

### 3. npm 生命周期钩子

```json
{
  "scripts": {
    "preinstall": "echo '安装前执行'",
    "postinstall": "echo '安装后执行'",
    "prebuild": "echo '构建前执行'",
    "postbuild": "echo '构建后执行'"
  }
}
```

## 包管理进阶

### 1. package-lock.json

```bash
# package-lock.json 的作用
# 锁定依赖版本，确保团队成员安装一致的依赖

# 更新锁文件
npm install
npm update

# 清理并重新安装
rm -rf node_modules package-lock.json
npm install
```

### 2. 常用 npm 命令

```bash
# 查看已安装的包
npm list
npm list --depth=0

# 查看过时的包
npm outdated

# 更新包
npm update
npm update <package-name>

# 卸载包
npm uninstall react
npm uninstall -D eslint

# 搜索包
npm search react

# 查看包信息
npm info react

# 查看包的使用量
npm view react downloads
```

### 3. 镜像源配置

```bash
# 查看当前镜像源
npm config get registry

# 切换为淘宝镜像
npm config set registry https://registry.npmmirror.com

# 切换为官方源
npm config set registry https://registry.npmjs.org

# 使用 nrm 管理镜像源
npm install -g nrm
nrm ls
nrm use taobao
```

## 深入思考

### 1. 依赖树与 hoisting

```bash
# npm 会将依赖提升到顶层（npm v3+）
# 但嵌套依赖仍可能产生版本冲突

# 查看依赖树
npm ls
npm ls react

# 查找重复依赖
npm ls --all | grep -E "duplicate|UNMET"
```

### 2. 语义化版本

```
主版本.次版本.修订版本
  ^       ^     ^
  |       |     └─ 补丁：向后兼容的 bug 修复
  |       └────── 新功能：向后兼容
  └────────────── 不兼容的 API 变更

# 版本范围
"react": "^18.2.0"    # >=18.2.0 <19.0.0
"react": "~18.2.0"    # >=18.2.0 <18.3.0
"react": "18.2.0"     # 精确版本
"react": ">=18.0.0"   # 大于等于
```

### 3. 依赖安装优化

```bash
# 使用 pnpm 替代 npm（节省磁盘空间，安装更快）
npm install -g pnpm
pnpm create vite my-app --template react
pnpm install
pnpm add react
pnpm add -D typescript

# 使用 yarn
npm install -g yarn
yarn create vite my-app --template react
yarn install
yarn add react
```

## 常见陷阱与最佳实践

### 1. 不要提交 node_modules

```bash
# .gitignore 中应包含
node_modules/
dist/
.env
```

### 2. 锁定依赖版本

```bash
# 始终提交 package-lock.json
# 确保团队成员安装一致的依赖版本

# 生产环境使用精确版本
npm install react@18.2.0 --save --save-exact
```

### 3. 定期更新依赖

```bash
# 检查过时依赖
npm outdated

# 安全更新
npm audit
npm audit fix

# 手动更新
npm update
```

### 4. 最佳实践

1. **区分生产依赖和开发依赖**，减小生产包体积
2. **提交 package-lock.json**，确保环境一致性
3. **不要提交 node_modules**，在 CI/CD 中重新安装
4. **定期更新依赖**，修复安全漏洞
5. **使用 nvm 管理 Node 版本**，避免版本冲突
6. **考虑使用 pnpm/yarn**，提升安装速度和磁盘效率
7. **敏感信息放入 .env**，不要提交到版本控制

## 总结

Node.js 和 npm 是 React 开发的基础：

- **Node.js**：JavaScript 运行时，提供执行环境和核心模块
- **npm**：包管理器，管理项目依赖和脚本命令
- **依赖分类**：生产依赖 vs 开发依赖
- **版本管理**：语义化版本、package-lock.json、nvm
