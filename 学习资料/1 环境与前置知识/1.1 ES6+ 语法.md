# ES6+ 语法详解：箭头函数、解构、模块化与常用特性

## ES6+ 的定义

ES6（ECMAScript 2015）及后续版本是 JavaScript 语言的重大升级，引入了大量新特性，成为现代 React 开发的基础。

**核心特点：**
- 提供了更简洁、更强大的语法
- 解决了传统 JavaScript 的诸多痛点
- React 项目大量依赖 ES6+ 特性

## 箭头函数

### 1. 基本语法

```jsx
// 传统函数
function add(a, b) {
  return a + b;
}

// 箭头函数
const add = (a, b) => a + b;

// 单参数可省略括号
const double = x => x * 2;

// 无参数需要空括号
const greet = () => 'Hello';

// 函数体多行时需要花括号和 return
const multiply = (a, b) => {
  const result = a * b;
  return result;
};
```

- **箭头函数语法**：`const add = (a, b) => a + b;` 使用 `=>` 定义箭头函数
- **省略花括号**：单行表达式可省略 `{}` 和 `return`，自动返回表达式结果
- **单参数省略括号**：`x => x * 2` 单参数时可省略参数的小括号
- **无参数空括号**：`() => 'Hello'` 无参数时必须写空括号
- **多行函数体**：`=> { ... }` 多行语句需要花括号和显式 `return`

---

### 2. 箭头函数的特点

```jsx
// 特点1：没有 this 绑定，继承外层作用域的 this
const obj = {
  name: 'React',
  // 箭头函数继承外层 this
  greet: () => {
    console.log(this); // window/全局对象，不是 obj
  },
  // 普通函数有 this 绑定
  greetNormal() {
    console.log(this); // obj
  }
};

// 特点2：没有 arguments 对象
const fn = (...args) => {
  console.log(args); // 使用剩余参数替代
};

// 特点3：不能用作构造函数
const Person = (name) => { this.name = name; };
new Person('小明'); // 报错：Person is not a constructor

// 特点4：没有 prototype 属性
console.log(fn.prototype); // undefined
```

- **this 绑定**：箭头函数没有自己的 `this`，继承外层作用域的 `this` 值
- **arguments 对象**：箭头函数没有 `arguments` 对象，使用剩余参数 `...args` 替代
- **构造函数**：箭头函数不能用 `new` 调用，没有 `prototype` 属性
- **剩余参数**：`...args` 将多个参数收集为数组，替代 `arguments` 对象

```jsx

```jsx
// 组件定义
const Greeting = ({ name }) => <h1>你好，{name}!</h1>;

// 事件处理
function Button() {
  return <button onClick={() => console.log('clicked')}>点击</button>;
}

// 数组方法
const numbers = [1, 2, 3];
const doubled = numbers.map(n => n * 2);
const evens = numbers.filter(n => n > 1);
```

- **组件定义**：`const Greeting = ({ name }) => ...` 箭头函数 + 对象解构定义函数组件
- **事件处理**：`() => console.log('clicked')` 箭头函数作为事件回调，简洁且无需绑定 this
- **map 方法**：`numbers.map(n => n * 2)` 遍历数组，每个元素乘以 2 返回新数组
- **filter 方法**：`numbers.filter(n => n > 1)` 过滤数组，返回满足条件的元素组成的新数组

## 解构赋值

### 1. 对象解构

```jsx
// 基本解构
const user = { name: '小明', age: 20, email: 'xiaoming@example.com' };
const { name, age } = user;
console.log(name); // 小明
console.log(age); // 20

// 重命名
const { name: userName, age: userAge } = user;

// 默认值
const { nickname = '默认昵称' } = user;

// 嵌套解构
const person = {
  name: '小明',
  address: { city: '北京', zip: '100000' }
};
const { address: { city } } = person;

// 在函数参数中使用
function Greeting({ name, age }) {
  return <p>{name}，{age}岁</p>;
};
```

- **对象解构**：`const { name, age } = user;` 从对象中提取属性，变量名需与属性名一致
- **重命名**：`const { name: userName }` 解构时重命名变量，避免命名冲突
- **默认值**：`const { nickname = '默认昵称' }` 属性不存在时使用默认值
- **嵌套解构**：`const { address: { city } }` 从嵌套对象中提取深层属性
- **函数参数解构**：`function Greeting({ name, age })` 直接从参数对象中解构，简化 props 访问

### 2. 数组解构

```jsx
// 基本解构
const colors = ['红色', '绿色', '蓝色'];
const [first, second] = colors;
console.log(first); // 红色

// 跳过元素
const [first, , third] = colors;
console.log(third); // 蓝色

// 默认值
const [first, second, third, fourth = '白色'] = colors;

// 剩余参数
const [head, ...tail] = colors;
console.log(tail); // ['绿色', '蓝色']

// 交换变量
let a = 1, b = 2;
[a, b] = [b, a];
```

- **数组解构**：`const [first, second] = colors;` 按位置从数组提取值到变量
- **跳过元素**：`const [first, , third]` 用空位跳过中间元素
- **默认值**：`const [first, fourth = '白色']` 数组元素不存在时使用默认值
- **剩余参数**：`const [head, ...tail]` 将剩余元素收集为数组
- **变量交换**：`[a, b] = [b, a]` 利用解构无需临时变量即可交换值

### 3. 解构的应用场景

```jsx
// 从 API 响应中提取数据
const fetchData = async () => {
  const { data, status } = await axios.get('/api/user');
  return data;
};

// 从 props 中提取
function UserProfile({ user: { name, avatar }, onFollow }) {
  return (
    <div>
      <img src={avatar} alt={name} />
      <button onClick={onFollow}>关注</button>
    </div>
  );
}

// 从 state 中提取
function Counter() {
  const [count, setCount] = useState(0);
  return <p>计数：{count}</p>;
};
```

- **API 响应解构**：`const { data, status } = await axios.get(...)` 从响应对象中提取 data 和 status
- **async/await**：`async () => {...}` 异步函数返回 Promise，await 等待异步结果
- **嵌套解构**：`{ user: { name, avatar } }` 从嵌套的 props 中直接提取深层属性
- **useState Hook**：`const [count, setCount] = useState(0)` 数组解构提取状态值和更新函数
- **JSX 表达式**：`{count}` 在 JSX 中渲染 JavaScript 表达式的值

## 模板字符串

### 1. 基本用法

```jsx
// 多行字符串
const message = `
  你好，
  欢迎学习 React！
`;

// 字符串插值
const name = 'React';
const version = 18;
const greeting = `框架：${name}，版本：${version}`;

// 表达式插值
const a = 5, b = 3;
const result = `${a} + ${b} = ${a + b}`;
```

- **反引号语法**：`` `...` `` 使用反引号定义模板字符串，支持多行和插值
- **字符串插值**：`${name}` 在模板字符串中嵌入变量，自动转换为字符串
- **表达式插值**：`${a + b}` 在模板字符串中执行任意表达式并插入结果

### 2. 标签模板
// 标签模板函数
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) => {
    return result + str + (values[i] ? `<mark>${values[i]}</mark>` : '');
  }, '');
}

const name = '小明';
const age = 20;
const html = highlight`姓名：${name}，年龄：${age}`;
// 结果：姓名：<mark>小明</mark>，年龄：<mark>20</mark>
```

- **标签模板**：`highlight` 后跟模板字符串，将模板作为函数调用
- **strings 参数**：`strings` 是被插值分割后的字符串数组
- **剩余参数**：`...values` 收集所有插值表达式的结果
- **reduce 拼接**：`strings.reduce(...)` 遍历字符串数组，将插值值插入对应位置

## 模块化

### 1. 导出与导入

```jsx
// 导出：命名导出
export const CONSTANT = 100;
export function add(a, b) { return a + b; }
export class User {}

// 导出：默认导出
export default function App() { return <div>App</div>; }

// 导入：命名导入
import { CONSTANT, add } from './utils';

// 导入：默认导入
import App from './App';

// 导入：重命名
import { add as plus } from './utils';

// 导入：全部
import * as utils from './utils';
```

- **命名导出**：`export const/function/class` 每个文件可有多个命名导出
- **默认导出**：`export default` 每个文件只能有一个默认导出
- **命名导入**：`import { CONSTANT, add }` 使用 `{}` 导入命名导出，需匹配导出名
- **默认导入**：`import App from './App'` 导入默认导出，可自定义名称
- **重命名导入**：`import { add as plus }` 导入时重命名，避免命名冲突
- **通配符导入**：`import * as utils` 将模块所有导出收集为对象

### 2. 模块最佳实践

```jsx
// 推荐：一个文件一个默认导出 + 多个命名导出
// utils.js
export const PI = 3.14159;
export function calculate(radius) { return PI * radius * radius; }
export default function logger() { console.log('logger'); }

// 使用
import log from './utils';
import { PI, calculate } from './utils';
```

- **默认导出 + 命名导出**：`export default` 导出主内容，`export const/function` 导出辅助功能
- **分别导入**：`import log` 导入默认导出，`import { PI, calculate }` 导入命名导出

## 常用 ES6+ 特性

### 1. let 和 const

```jsx
// let：块级作用域，可重新赋值
let count = 0;
count = 1;

// const：块级作用域，不可重新赋值
const MAX = 100;
// MAX = 200; // 报错

// 注意：const 对象属性可以修改
const user = { name: '小明' };
user.name = '小红'; // 允许
user = {}; // 报错
```

- **let 声明**：`let count` 块级作用域变量，可重新赋值，不存在变量提升
- **const 声明**：`const MAX` 块级作用域常量，声明后不可重新赋值
- **const 对象属性**：`user.name = '小红'` const 只保证引用不变，对象属性仍可修改

### 2. 展开运算符与剩余参数

```jsx
// 对象展开
const user = { name: '小明', age: 20 };
const extendedUser = { ...user, email: 'xiaoming@example.com', role: 'admin' };

// 数组展开
const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = [...arr1, ...arr2]; // [1, 2, 3, 4]

// 剩余参数
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // 6
```

- **对象展开**：`{ ...user, email }` 复制对象属性并添加新属性，创建浅拷贝
- **数组展开**：`[...arr1, ...arr2]` 合并多个数组，创建新数组
- **剩余参数**：`function sum(...numbers)` 函数定义中收集多余参数为数组
- **reduce 方法**：`numbers.reduce((a, b) => a + b, 0)` 累加数组元素，初始值为 0

### 3. Promise 与 async/await

```jsx
// Promise
const fetchData = new Promise((resolve, reject) => {
  setTimeout(() => resolve('数据'), 1000);
});

fetchData.then(data => console.log(data));

// async/await
async function loadData() {
  try {
    const data = await fetchData();
    console.log(data);
  } catch (error) {
console.error(error);
  }
};
```

- **Promise 构造**：`new Promise((resolve, reject) => {...})` 创建异步操作包装
- **resolve/reject**：`resolve('数据')` 成功时调用，`reject` 失败时调用
- **then 链式调用**：`fetchData.then(data => {...})` 处理 Promise 成功结果
- **async 函数**：`async function loadData()` 返回 Promise，内部可使用 await
- **await 关键字**：`await fetchData()` 等待 Promise 解析，语法上同步异步代码
- **try/catch**：捕获异步操作中的错误，替代 `.catch()`

### 4. Map 和 Set

```jsx
// Set：去重集合
const unique = new Set([1, 2, 2, 3, 3]);
console.log(unique); // Set {1, 2, 3}

// Map：键值对集合
const map = new Map();
map.set('name', '小明');
map.get('name'); // 小明
```

- **Set 去重**：`new Set([1, 2, 2, 3])` 自动去除重复元素，利用值相等性判断
- **Map 创建**：`new Map()` 创建键值对集合，键可以是任意类型
- **set/get 方法**：`map.set('name', '小明')` 设置键值对，`map.get('name')` 读取值

### 5. 可选链与空值合并

```jsx
const user = { profile: { name: '小明' } };

// 可选链
const name = user?.profile?.name; // 避免 'Cannot read property' 错误
const city = user?.address?.city ?? '未知';

// 空值合并运算符
const value = null ?? '默认值'; // '默认值'
const zero = 0 ?? 100; // 0（仅 null/undefined 时使用默认值）
```

- **可选链**：`user?.profile?.name` 安全访问深层属性，属性不存在时返回 undefined 而非报错
- **空值合并**：`??` 仅在左侧为 null 或 undefined 时使用右侧默认值
- **与 || 的区别**：`0 ?? 100` 返回 0（0 不是 null/undefined），而 `0 || 100` 返回 100

## 深入思考

### 1. 箭头函数的 this 陷阱

```jsx
function Timer() {
  this.count = 0;
  // 错误：箭头函数继承外层 this（window）
  setInterval(() => {
    this.count++; // this 不是 Timer 实例
  }, 1000);
}

// 正确：使用普通函数
function Timer() {
  this.count = 0;
  setInterval(function() {
    this.count++; // this 是 Timer 实例
  }.bind(this), 1000);
}
```

- **箭头函数 this**：`setInterval(() => {...})` 箭头函数继承外层 this，此处是 window 而非 Timer 实例
- **普通函数 this**：`setInterval(function() {...}, 1000)` 普通函数的 this 指向调用者
- **bind 绑定**：`.bind(this)` 将外层 this 显式绑定到回调函数，确保 this 指向正确

### 2. const 的不可变陷阱

```jsx
// const 只保证引用不变，不保证内容不变
const user = { name: '小明' };
user.name = '小红'; // 允许：修改属性
user = {}; // 报错：重新赋值

// 深冻结
const deepFreeze = (obj) => {
  Object.keys(obj).forEach(key => {
    if (typeof obj[key] === 'object') deepFreeze(obj[key]);
  });
  return Object.freeze(obj);
};
```

- **const 引用不变**：`const user = {...}` 变量引用不可变，但对象属性可修改
- **Object.freeze**：`Object.freeze(obj)` 冻结对象，使所有属性变为只读
- **递归深冻结**：`deepFreeze(obj[key])` 递归遍历嵌套对象，逐层冻结

### 3. 展开运算符的浅拷贝问题

```jsx
const user = { name: '小明', address: { city: '北京' } };
const copiedUser = { ...user };

copiedUser.address.city = '上海';
console.log(user.address.city); // 上海（浅拷贝，嵌套对象共享引用）

// 深拷贝需要递归或使用库
import { structuredClone } from 'util';
const deepCopied = structuredClone(user);
```

- **展开运算符浅拷贝**：`{ ...user }` 只复制一层属性，嵌套对象仍共享引用
- **修改嵌套属性**：`copiedUser.address.city = '上海'` 影响原对象，因为 address 是同一引用
- **structuredClone**：`structuredClone(user)` 深拷贝对象，嵌套对象也会独立复制

## 常见陷阱与最佳实践

### 1. 箭头函数适用场景

| 场景 | 推荐 | 说明 |
|------|------|------|
| 回调函数 | 箭头函数 | 简洁，无需担心 this |
| 对象方法 | 普通函数 | 需要 this 绑定 |
| 构造函数 | 普通函数 | 箭头函数不能 new |
| 事件处理 | 箭头函数 | 在类组件中避免 this 问题 |

### 2. 最佳实践

1. **优先使用 const**，需要重新赋值时用 let，避免使用 var
2. **解构函数参数**，提升代码可读性
3. **箭头函数用于回调**，普通函数用于对象方法和构造函数
4. **展开运算符用于浅拷贝**，深拷贝使用专用方法
5. **使用可选链**简化深层属性访问
6. **模块化开发**，一个文件一个默认导出
