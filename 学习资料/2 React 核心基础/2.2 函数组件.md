# 函数组件详解：定义、渲染与使用

---

## 函数组件的定义

函数组件是 React 中最基础的组件形式，它是一个**纯 JavaScript 函数**，接收 props 作为参数，返回 JSX 描述 UI 结构。

**核心特点：**
- 本质是函数，输入 props，输出 JSX
- 配合 Hooks 拥有完整的能力（状态、副作用等）
- 是 React 官方推荐的主要组件编写方式

## 函数组件基本用法

### 1. 最简单的函数组件

```jsx
function Greeting() {
  return <h1>你好，React!</h1>;
}
```

- **函数组件定义**：`function Greeting` 是函数组件定义，函数名使用大驼峰命名
- **返回 JSX**：`return <h1>你好，React!</h1>` 返回 JSX 元素，描述要渲染的 UI
- **命名规范**：组件名首字母必须大写，否则 React 会将其当作 HTML 标签处理

### 2. 接收 props 的函数组件

```jsx
function Greeting({ name }) {
  return <h1>你好，{name}!</h1>;
}

// 使用
<Greeting name="小明" />
```

- **参数解构**：`({ name })` 是参数解构，从 props 对象中提取 name 属性
- **JSX 表达式**：`{name}` 是 JSX 中的表达式，渲染 props.name 的值
- **组件使用**：`<Greeting name="小明" />` 是使用组件的语法，`name="小明"` 是传递的 prop

### 3. 箭头函数写法

```jsx
const Greeting = ({ name }) => <h1>你好，{name}!</h1>;
```

- **变量声明**：`const Greeting =` 使用变量声明组件，组件名使用大驼峰
- **箭头函数**：`({ name }) =>` 是箭头函数参数，解构 props
- **隐式返回**：箭头函数体只有一行 JSX 时，可以省略花括号和 return

### 4. 组件命名规范

```jsx
// 正确：大驼峰命名
function UserProfile() {}
const UserProfile = () => {};

// 错误：小驼峰命名（会被当作普通 HTML 标签）
function userProfile() {}
```

- **大驼峰命名**：组件名必须使用大驼峰（PascalCase），如 `UserProfile`、`TodoItem`
- **小驼峰陷阱**：小驼峰（camelCase）如 `userProfile` 会被 React 当作 HTML 标签处理

## 函数组件的渲染过程

### 1. 渲染流程

```
组件调用 → 执行函数体 → 返回 JSX → 构建虚拟 DOM → 差异对比 → 更新真实 DOM
```

```jsx
function Counter() {
  console.log('组件被调用（渲染）');
  return <h1>计数器</h1>;
}

// 每次渲染，Counter 函数都会被重新执行
```

### 2. 纯函数要求

函数组件应该是**纯函数**——给定相同的 props，始终返回相同的 JSX：

```jsx
// 正确：纯函数
function Greeting({ name }) {
  return <h1>你好，{name}!</h1>;
}

// 错误：非纯函数，依赖外部可变状态
let count = 0;
function Counter() {
  count++;
  return <p>渲染了 {count} 次</p>;
}
```

- **纯函数**：相同输入（props）始终产生相同输出（JSX）
- **外部可变状态**：`let count = 0` 是组件外部的可变状态，违反纯函数原则

## 常见陷阱与最佳实践

### 1. 组件拆分原则

- **单一职责**：每个组件只做一件事
- **可复用性**：通用 UI 提取为独立组件
- **合理粒度**：不要太细（增加嵌套）也不要太粗（难以维护）
- **建议**：一个组件不超过 100-150 行

### 2. 最佳实践

1. **优先使用函数组件**，类组件已过时
2. **组件名使用大驼峰**，文件命名建议使用 PascalCase
3. **保持组件纯函数特性**，副作用放在 useEffect 中
4. **组件拆分遵循单一职责**，便于测试和维护
5. **默认 props 使用默认参数**：`function Component({ name = '默认' })`

---

## 总结

函数组件是 React 的核心构建块：

- **定义**：接收 props，返回 JSX 的纯函数
- **渲染**：每次渲染重新执行函数体，基于最新 props 和 state 生成 UI
- **组合**：通过 props 组合组件，而非继承
