# Props 详解：数据传递与单向数据流

---

## Props 的定义

Props（properties 的缩写）是 React 组件之间传递数据的机制。父组件通过 props 向子组件传递数据，子组件接收 props 并渲染 UI。

**核心特点：**
- Props 是只读的，组件不能修改自己的 props
- 数据流动是单向的：父 → 子
- Props 可以是任何 JavaScript 类型（字符串、数字、对象、数组、函数、JSX 等）

## Props 基本用法

### 1. 传递基本类型 Props

```jsx
function Greeting({ name, age }) {
  return (
    <div>
      <p>姓名：{name}</p>
      <p>年龄：{age}</p>
    </div>
  );
}

// 使用
<Greeting name="小明" age={20} />
```

- **参数解构**：`({ name, age })` 从 props 对象中提取 name 和 age 属性
- **字符串 prop**：`name="小明"` 用引号包裹字符串值
- **表达式 prop**：`age={20}` 用花括号包裹 JavaScript 值

### 2. 传递函数（回调）

```jsx
function Button({ onClick, label }) {
  return <button onClick={onClick}>{label}</button>;
}

// 使用
<Button label="点击" onClick={() => alert('clicked')} />
```

- **函数解构**：`({ onClick, label })` 解构出 onClick 函数和 label 字符串
- **事件绑定**：`onClick={onClick}` 将 prop 中的函数绑定到按钮点击事件
- **箭头函数 prop**：`onClick={() => alert('clicked')}` 传递箭头函数作为 prop

### 3. children Prop

React 自动将所有嵌套内容传递给 `children` prop：

```jsx
function Card({ children }) {
  return <div className="card">{children}</div>;
}

// 使用
<Card>
  <p>这是卡片内容</p>
  <button>操作</button>
</Card>
```

- **children prop**：`{children}` 是特殊 prop，无需显式声明，React 自动提供
- **隐式传递**：`<Card>...</Card>` 标签内的所有内容自动成为 children

## Props 默认值与类型检查

### 1. 默认参数（推荐）

```jsx
function Greeting({ name = '访客' }) {
  return <h1>你好，{name}!</h1>;
}
```

- `{ name = '访客' }` 是默认参数语法，当 name 未传入时使用 '访客'
- 推荐优先使用默认参数而非 defaultProps

## Props 深入思考

### 1. 单向数据流

Props 是单向的，子组件不能直接修改 props：

```jsx
// 正确：通过回调函数让父组件更新状态
function Counter({ count, onIncrement }) {
  return <button onClick={onIncrement}>{count}</button>;
}
```

- **只读 prop**：子组件不能修改 props
- **回调函数**：`onIncrement` 是回调函数 prop，子组件调用它通知父组件更新
- **单向数据流**：子组件通过调用回调函数，让父组件更新 state，再传递新的 props

### 2. Props 是只读的快照

每次父组件渲染时，都会创建新的 props 对象传递给子组件：

```jsx
function Parent() {
  const [count, setCount] = useState(0);
  return <Child count={count} />;
}

function Child({ count }) {
  // count 是当前渲染的快照值
}
```

- **状态传递**：`count={count}` 将父组件的 state 值作为 prop 传递给子组件
- **prop 解构**：`({ count })` 在子组件中解构接收 prop
- **快照值**：count 是当前渲染时的快照值

## 常见陷阱与最佳实践

### 1. 事件绑定语法

```jsx
// 正确：传递函数引用
<button onClick={handleClick}>点击</button>

// 错误：立即执行函数
<button onClick={handleClick()}>点击</button>

// 正确：需要传参时使用箭头函数
<button onClick={() => handleClick(id)}>点击</button>
```

### 2. 最佳实践

1. **Props 只读**，永远不要修改 props
2. **使用默认参数**替代 defaultProps（更简洁）
3. **TypeScript 替代 PropTypes**，获得编译时类型检查
4. **通过回调函数实现子→父通信**，保持单向数据流
5. **children 是特殊 prop**，无需显式声明即可使用

---

## 总结

Props 是 React 数据传递的核心机制：

- **传递**：可以是任何类型，包括基本值、对象、函数、JSX
- **单向**：父→子单向流动，子组件不能修改 props
- **只读**：props 是只读的快照，确保数据可预测
