# JSX 详解：语法、规则与工作原理

---

## JSX 的定义

JSX（JavaScript XML）是 React 的核心特性之一，允许你在 JavaScript 中编写类似 HTML 的结构。

**核心特点：**
- JSX 是 JavaScript 的语法糖，最终会被编译为 `React.createElement()` 调用
- 必须在 `.jsx` 或 `.tsx` 文件中使用

- [JSX 介绍（中文）](https://zh-hans.react.dev/learn/writing-markup-with-jsx)

## JSX 基本语法

### 1. 基础用法

```jsx
const element = <h1>Hello, React!</h1>;

function Greeting() {
  return (
    <div>
      <h2>欢迎学习 React</h2>
      <p>JSX 让 UI 描述更直观</p>
    </div>
  );
}
```

- **JSX 表达式**：`<h1>Hello, React!</h1>` 是 JSX 语法，描述要渲染的 UI 结构
- **JSX 赋值**：`const element =` 将 JSX 赋值给变量，JSX 本质是 JavaScript 表达式
- **函数返回 JSX**：`return (...)` 函数组件返回 JSX，描述组件的 UI
- **多行 JSX 括号**：`(...)` 多行 JSX 必须用括号包裹，否则会自动插入分号导致错误

### 2. 在 JSX 中嵌入 JavaScript 表达式

使用花括号 `{}` 可以在 JSX 中嵌入任何 JavaScript 表达式：

```jsx
const name = 'React';
const version = 18;

function Info() {
  return (
    <div>
      <p>框架：{name}</p>
      <p>版本：{version}</p>
      <p>计算结果：{2 + 3}</p>
      <p>条件：{true ? '成立' : '不成立'}</p>
    </div>
  );
}
```

- **JSX 表达式**：`{name}` 在 JSX 中嵌入变量，渲染 `name` 的值
- **JSX 表达式**：`{version}` 在 JSX 中嵌入变量，渲染 `version` 的值
- **JSX 表达式**：`{2 + 3}` 在 JSX 中嵌入算术表达式，渲染计算结果 `5`
- **JSX 表达式**：`{true ? '成立' : '不成立'}` 在 JSX 中嵌入三元运算符，渲染条件结果

## JSX 核心规则

### 1. 必须返回单个根元素

```jsx
// 错误：多个根元素
return <h1>标题</h1><p>段落</p>;

// 正确：使用 Fragment 或 div 包裹
return (
  <>
    <h1>标题</h1>
    <p>段落</p>
  </>
);
```

- **Fragment 语法**：`<>...</>` 是 Fragment 简写，不产生额外 DOM 节点
- **Fragment 作用**：包裹多个元素，满足"单个根元素"规则
- **错误写法**：`<h1>...</h1><p>...</p>` 多个根元素违反 JSX 规则

### 2. 闭合标签

所有标签必须闭合，自闭合标签需加 `/`：

```jsx
<img src={avatar} alt="头像" />
<input type="text" />
```

- **自闭合标签**：`<img ... />` 自闭合标签必须加 `/`
- **自闭合标签**：`<input ... />` 没有子元素的标签必须自闭合

### 3. 驼峰命名

HTML 属性在 JSX 中使用驼峰命名：

```jsx
// HTML 写法
<div class="container" onclick="handler()">

// JSX 写法
<div className="container" onClick={handler}>
```

- **className 属性**：`className="container"` 使用 className 而非 class（class 是 JS 保留字）
- **onClick 属性**：`onClick={handler}` 事件属性使用驼峰命名

### 4. 样式处理

JSX 中的 `style` 属性接收对象而非字符串：

```jsx
<div style={{ color: 'red', fontSize: '14px' }}>

const isActive = true;
<div style={{ color: isActive ? 'red' : 'gray', fontSize: '14px' }}>
```

- **style 对象**：`style={{ color: 'red' }}` 接收对象而非字符串
- **双花括号**：`{{ color: 'red' }}` 外层 `{}` 是 JSX 表达式，内层 `{}` 是 JavaScript 对象
- **条件样式**：`color: isActive ? 'red' : 'gray'` 在样式对象中使用三元运算符

## JSX 的工作原理

JSX 不是浏览器原生支持的语法，需要经过编译工具（如 Babel、TypeScript）转换为纯 JavaScript：

```jsx
// 原始 JSX
const element = <h1 className="title">Hello</h1>;

// 编译后
const element = React.createElement(
  'h1',
  { className: 'title' },
  'Hello'
);
```

- **JSX 语法**：`<h1 className="title">Hello</h1>` 是 JSX 写法，人类可读
- **编译产物**：`React.createElement(...)` 是编译后的 JavaScript，浏览器可执行
- **createElement 参数**：第一个参数 `'h1'` 是标签名，第二个参数 `{ className: 'title' }` 是属性，第三个参数 `'Hello'` 是子节点

## 常见陷阱与最佳实践

### 1. 属性引号与表达式混用

```jsx
// 正确：属性用引号，表达式用花括号
<div className="container" id={dynamicId}>

// 错误：混用导致语法错误
<div className={container} id="myId">
```

- **属性引号**：`className="container"` 静态属性值用引号
- **JSX 表达式**：`id={dynamicId}` 动态属性值用花括号
- **错误写法**：`className={container}` 没有花括号的标识符会被当作字符串，不是变量

### 2. 换行与括号

当 JSX 跨多行时，建议用括号包裹：

```jsx
// 推荐
const content = (
  <div>
    <h1>标题</h1>
    <p>内容</p>
  </div>
);
```

- **括号包裹**：`(...)` 多行 JSX 用括号包裹，避免自动插入分号

### 3. 事件处理函数传递

```jsx
// 正确：传递函数引用
<button onClick={handleClick}>点击</button>

// 错误：立即调用函数
<button onClick={handleClick()}>点击</button>

// 正确：需要传参时使用箭头函数
<button onClick={() => handleClick(id)}>点击</button>
```

- **函数引用**：`onClick={handleClick}` 传递函数引用，点击时调用
- **立即调用**：`onClick={handleClick()}` 渲染时立即执行，不是点击时执行
- **箭头函数传参**：`onClick={() => handleClick(id)}` 用箭头函数包装，点击时调用并传参

### 4. 最佳实践

1. **使用 Fragment 而非多余 div**，减少 DOM 嵌套
2. **key 使用唯一稳定的 ID**，避免使用索引（除非列表静态不变）
3. **条件渲染优先使用短路表达式或三元运算符**，避免 if/else
4. **style 对象使用驼峰命名**，多个相同样式提取为变量
5. **长 JSX 适当换行**，提升可读性
6. **始终处理 null/undefined 状态**，避免渲染空白

---

## 总结

JSX 是 React 的标志性特性，它将 UI 描述与 JavaScript 逻辑无缝结合：

- **语法**：类似 HTML，但遵循 JavaScript 规则（驼峰命名、花括号嵌入表达式）
- **本质**：`React.createElement()` 的语法糖，编译后生成普通 JavaScript 对象
- **安全**：默认转义所有嵌入值，防止 XSS 攻击
- **性能**：通过虚拟 DOM 和 key 机制实现高效更新
