# 事件处理详解：事件绑定与表单处理

---

## 事件处理的定义

React 事件处理是用户交互（点击、输入、提交等）触发组件响应的机制。React 使用**合成事件（SyntheticEvent）**系统，封装了原生浏览器事件。

**核心特点：**
- 事件命名使用驼峰格式（`onClick` 而非 `onclick`）
- 需要使用 `onClick={handler}` 语法绑定（而非 `onClick={handler()}`）

## 事件处理基本用法

### 1. 基本事件绑定

```jsx
function Button() {
  function handleClick() {
    alert('按钮被点击了');
  }

  return <button onClick={handleClick}>点击我</button>;
}
```

- **事件处理函数**：`function handleClick` 定义在组件内部
- **事件 prop 绑定**：`onClick={handleClick}` 绑定 handleClick 函数引用
- **点击执行**：点击按钮时，React 调用 handleClick 函数

### 2. 内联事件处理

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>计数：{count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(count - 1)}>-1</button>
    </div>
  );
}
```

- **箭头函数事件**：`onClick={() => setCount(count + 1)}` 点击时调用 setCount
- **内联适用场景**：适合简单逻辑，复杂逻辑建议提取为命名函数

### 3. 常见事件类型

| 事件 | 说明 | 事件 | 说明 |
|------|------|------|------|
| onClick | 点击 | onChange | 输入变化 |
| onSubmit | 表单提交 | onKeyDown | 按键按下 |
| onMouseEnter | 鼠标进入 | onFocus | 获得焦点 |

## 事件对象

### 1. 合成事件对象

```jsx
function Input() {
  const handleChange = (event) => {
    console.log(event.target.value);  // 输入的值
    console.log(event.type);          // 事件类型
  };

  return <input onChange={handleChange} />;
}
```

- **事件目标**：`event.target` 是被触发事件的 DOM 元素
- **元素值**：`event.target.value` 是该元素的当前值

### 2. 表单提交处理

```jsx
function Form() {
  const handleSubmit = (event) => {
    event.preventDefault();  // 阻止表单默认提交行为

    const formData = new FormData(event.target);
    const username = formData.get('username');
    const password = formData.get('password');

    console.log(username, password);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="username" />
      <input name="password" type="password" />
      <button type="submit">登录</button>
    </form>
  );
}
```

- **阻止默认行为**：`event.preventDefault()` 阻止表单默认提交行为
- **FormData**：`new FormData(event.target)` 从 form 元素中收集所有 input 的值
- **提交事件**：`onSubmit={handleSubmit}` 将 handleSubmit 绑定到表单提交事件

## 表单事件处理

### 1. 受控组件

```jsx
function ControlledForm() {
  const [name, setName] = useState('');
  const [email, setEmail] = useState('');

  const handleSubmit = (event) => {
    event.preventDefault();
    console.log(name, email);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={name} onChange={e => setName(e.target.value)} />
      <input value={email} onChange={e => setEmail(e.target.value)} />
      <button type="submit">提交</button>
    </form>
  );
}
```

- **受控绑定**：`value={name}` 将 state 绑定到输入框，state 是输入框的数据源
- **onChange 更新**：`onChange={e => setName(e.target.value)}` 输入变化时更新 state
- **受控组件**：输入框的值完全由 state 控制

### 2. 非受控组件

```jsx
function UncontrolledForm() {
  const nameRef = useRef(null);

  const handleSubmit = (event) => {
    event.preventDefault();
    console.log(nameRef.current.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input ref={nameRef} />
      <button type="submit">提交</button>
    </form>
  );
}
```

- **useRef 创建**：`useRef(null)` 创建 ref 对象，用于引用 DOM 元素
- **ref 绑定**：`ref={nameRef}` 将 ref 绑定到 DOM 元素
- **DOM 值读取**：`nameRef.current.value` 从真实 DOM 读取值

## 常见陷阱与最佳实践

### 1. 事件绑定语法

```jsx
// 正确：传递函数引用
<button onClick={handleClick}>点击</button>

// 错误：立即执行函数
<button onClick={handleClick()}>点击</button>

// 正确：需要传参时使用箭头函数
<button onClick={() => handleClick(id)}>点击</button>
```

### 2. 事件处理中的异步操作

```jsx
function DataButton() {
  const [loading, setLoading] = useState(false);

  const handleClick = async () => {
    setLoading(true);
    try {
      const data = await fetchData();
      setData(data);
    } catch (error) {
      console.error(error);
    } finally {
      setLoading(false);
    }
  };

  return <button onClick={handleClick} disabled={loading}>加载数据</button>;
}
```

- **async/await**：处理异步操作
- **loading 状态**：`setLoading(true)` 点击时设置 loading 为 true
- **禁用按钮**：`disabled={loading}` 加载期间禁用按钮，防止重复点击

### 3. 最佳实践

1. **传递函数引用**，避免 `onClick={handler()}` 立即执行
2. **使用命名函数**而非内联箭头函数，提升可读性
3. **受控组件处理表单**，便于实时验证和数据管理
4. **使用更新函数**处理基于当前状态的更新

---

## 总结

React 事件处理是用户交互的核心：

- **绑定**：使用驼峰命名，传递函数引用而非调用结果
- **合成事件**：跨浏览器一致，自动管理生命周期
- **表单**：受控组件（推荐）vs 非受控组件
