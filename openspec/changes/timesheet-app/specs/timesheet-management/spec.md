## ADDED Requirements

### Requirement: 工时条目数据模型
系统必须定义工时条目的数据结构，包含以下字段：
- id: 唯一标识符（字符串）
- date: 工作日期（字符串，格式 YYYY-MM-DD）
- project: 项目名称（字符串）
- taskType: 任务类型（字符串，可选值：开发、设计、会议、学习、其他）
- description: 任务描述（字符串）
- hours: 工时数（数字，范围 0.5-12）
- createdAt: 创建时间戳（数字）
- updatedAt: 更新时间戳（数字）

#### Scenario: 创建工时条目
- **WHEN** 用户填写表单并提交
- **THEN** 系统创建一个新的工时条目，分配唯一 id，设置当前日期和时间戳

#### Scenario: 工时数验证
- **WHEN** 用户输入工时数
- **THEN** 系统必须拒绝小于 0.5 或大于 12 的值，并显示错误提示

### Requirement: 添加工时记录
系统必须允许用户添加新的工时记录。

#### Scenario: 成功添加工时
- **WHEN** 用户填写所有必填字段（日期、项目、任务类型、描述、工时）并提交
- **THEN** 系统创建工时条目并添加到列表中

#### Scenario: 表单验证失败
- **WHEN** 用户提交缺少必填字段或工时数超出范围的表单
- **THEN** 系统显示对应的错误提示，不创建工时条目

#### Scenario: 必填字段校验
- **WHEN** 用户未填写项目名称或任务描述即提交
- **THEN** 系统必须在对应字段下方显示错误提示

### Requirement: 编辑工时记录
系统必须允许用户编辑已有的工时记录。

#### Scenario: 进入编辑模式
- **WHEN** 用户点击工时条目的编辑按钮
- **THEN** 系统进入编辑模式，表单中填充该条目的数据

#### Scenario: 保存编辑
- **WHEN** 用户在编辑模式下修改数据并提交
- **THEN** 系统更新工时条目，更新时间戳，并退出编辑模式

#### Scenario: 取消编辑
- **WHEN** 用户在编辑模式下点击取消按钮
- **THEN** 系统退出编辑模式，不保存任何更改

### Requirement: 删除工时记录
系统必须允许用户删除工时记录。

#### Scenario: 确认删除
- **WHEN** 用户点击工时条目的删除按钮
- **THEN** 系统弹出确认对话框，用户确认后才删除该条目

#### Scenario: 取消删除
- **WHEN** 用户在确认对话框中点击取消
- **THEN** 系统不删除该条目，保持列表不变

### Requirement: 查询工时记录
系统必须支持通过 id 查询工时记录。

#### Scenario: 通过 id 查询
- **WHEN** 系统根据 id 查询工时条目
- **THEN** 系统返回匹配的工时条目，未找到时返回 null

### Requirement: 事件处理
系统必须使用 React 事件处理机制响应用户交互。

#### Scenario: 表单输入事件
- **WHEN** 用户在表单中输入数据
- **THEN** 系统通过 onChange 事件处理函数实时更新表单状态

#### Scenario: 表单提交事件
- **WHEN** 用户点击提交按钮或按回车键
- **THEN** 系统通过 onSubmit 事件处理函数触发表单提交逻辑

### Requirement: JSX 与函数组件
系统必须使用 JSX 语法和函数组件构建所有 UI 组件。

#### Scenario: 组件渲染
- **WHEN** 系统渲染工时应用
- **THEN** 所有组件必须使用函数组件语法（不类组件）

### Requirement: Props 传递
系统必须通过 Props 在组件间传递数据和回调函数。

#### Scenario: 父子组件通信
- **WHEN** 父组件需要向子组件传递数据
- **THEN** 系统通过 Props 传递数据和回调函数

### Requirement: State 管理
系统必须使用 State 管理组件级数据。

#### Scenario: 表单状态更新
- **WHEN** 用户与表单交互
- **THEN** 系统通过 useState Hook 管理表单状态并触发重新渲染

### Requirement: 条件渲染
系统必须根据状态条件性地渲染不同的 UI。

#### Scenario: 空状态展示
- **WHEN** 工时列表为空
- **THEN** 系统显示空状态提示，而非空白区域

#### Scenario: 编辑模式切换
- **WHEN** 用户进入或退出编辑模式
- **THEN** 系统根据编辑状态条件渲染表单或只读视图

### Requirement: 列表渲染
系统必须使用 React 列表渲染功能展示工时条目。

#### Scenario: 工时列表展示
- **WHEN** 系统中存在工时条目
- **THEN** 系统使用 map 方法遍历数据并渲染工时条目列表
