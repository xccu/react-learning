> 创建日期：2026-09-03

## 1. 用户查询不起作用

**现象：** 在用户列表页使用查询表单（用户名/角色）进行筛选时，点击"查询"后列表无变化

**原因：** `UserQueryForm` 混用了 Ant Design 的 `Form` 和 `react-hook-form` 的 `register`，导致 `Select` 组件的值无法正确传递。具体表现为：
1. `Select` 组件不兼容 `register`，选择角色后值不会写入表单
2. Select 默认选项 `value: ''`（空字符串）导致选择"全部"时传空字符串，`mockAdapter` 的 `hasQuery` 检查把空字符串当 falsy，走成了 `getUsers()` 而非 `queryUsers()`

**解决方案：**
1. 移除 `react-hook-form`，改用 Ant Design 原生的 `Form.useForm()`
2. Select 的默认选项值从 `''` 改为 `undefined`

**文件：** `src/components/timesheet/UserQueryForm.tsx`

```tsx
// 修复前：混用 Ant Design Form 和 react-hook-form，Select 值无法正确传递
import { useForm } from 'react-hook-form'
import { Form, Input, Select, Button, Space } from 'antd'

const ROLE_OPTIONS: { value: UserRole; label: string }[] = [
  { value: '', label: '全部' },  // ← 修复行：空字符串导致 hasQuery 判断失败
  { value: '管理员', label: '管理员' },
  { value: '普通用户', label: '普通用户' },
]

function UserQueryForm({ onQuery, onCreate }: UserQueryFormProps) {
  const { register, handleSubmit, reset } = useForm({
    defaultValues: { username: '', role: '' },
  })

  const handleFormSubmit = (values: Record<string, string>) => {
    onQuery({
      username: values.username?.trim(),
      role: values.role as any,  // ← 修复行：Select 值无法通过 register 获取
    })
  }

  return (
    <Form layout="inline" onFinish={handleSubmit(handleFormSubmit)} className={styles.form}>
      <Form.Item label="用户名" {...register('username')}>  {/* ← 修复行：register 不兼容 Ant Design Select */}
        <Input allowClear placeholder="请输入用户名" />
      </Form.Item>
      <Form.Item label="角色" {...register('role')}>  {/* ← 修复行：同上 */}
        <Select allowClear placeholder="请选择角色" options={ROLE_OPTIONS} />
      </Form.Item>
      {/* ... */}
    </Form>
  )
}
```

```tsx
// 修复后：纯 Ant Design Form.useForm
import { Form, Input, Select, Button, Space } from 'antd'

const ROLE_OPTIONS: { value: UserRole | undefined; label: string }[] = [
  { value: undefined, label: '全部' },  // ← 修复行：undefined 而非空字符串
  { value: '管理员', label: '管理员' },
  { value: '普通用户', label: '普通用户' },
]

function UserQueryForm({ onQuery, onCreate }: UserQueryFormProps) {
  const [form] = Form.useForm<{ username?: string; role?: UserRole }>()

  const handleFormSubmit = (values: { username?: string; role?: UserRole }) => {
    onQuery({
      username: values.username?.trim() || undefined,
      role: values.role,
    })
  }

  const handleClear = () => {
    form.resetFields()
    onQuery({})
  }

  return (
    <Form form={form} layout="inline" onFinish={handleFormSubmit} className={styles.form}>
      <Form.Item label="用户名" name="username">
        <Input allowClear placeholder="请输入用户名" />
      </Form.Item>
      <Form.Item label="角色" name="role">
        <Select allowClear placeholder="请选择角色" options={ROLE_OPTIONS} />
      </Form.Item>
      {/* ... */}
    </Form>
  )
}
```

## 2. 详情页角色只显示一个

**现象：** 用户详情页的角色字段只显示第一个角色（如 `user.roles[0]`），如果用户有多个角色则只显示一个

**原因：** `UserDetailPage` 使用了 `user.roles[0]` 取第一个角色，而非遍历 `roles` 数组。列表页已有正确的多角色渲染逻辑（`roles.map()` + `Space`），详情页未保持一致

**解决方案：** 改为遍历 `user.roles` 数组渲染多个 `Tag`

**文件：** `src/pages/UserDetailPage.tsx`

```tsx
// 修复前：只取第一个角色
<div className={styles.field}>
  <label className={styles.label}>角色</label>
  <div className={styles.value}>
    <Tag color={roleColor[user.roles[0]]}>{user.roles[0]}</Tag>  {/* ← 修复行：只取第一个 */}
  </div>
</div>

// 修复后：遍历 roles 数组
<div className={styles.field}>
  <label className={styles.label}>角色</label>
  <div className={styles.value}>
    <Space size="small">
      {user.roles.map((role) => (
        <Tag key={role} color={roleColor[role]}>{role}</Tag>
      ))}
    </Space>
  </div>
</div>
```

## 3. 详情页 `Space is not defined`

**现象：** 修复问题2后，详情页显示空白，控制台报 `Uncaught ReferenceError: Space is not defined`

**原因：** 问题2的修复中使用了 `<Space>` 组件包裹多个 `Tag`，但 `UserDetailPage` 的 import 语句中遗漏了 `Space`

**解决方案：** 补充 `Space` 的 import

**文件：** `src/pages/UserDetailPage.tsx`

```tsx
// 修复前：缺少 Space 导入
import { Tag } from 'antd'

// 修复后：补充 Space
import { Tag, Space } from 'antd'
```

## 4. 用户管理 Redux 完善（async thunks）

**背景：** 第 5 周引入 Redux 管理用户状态时，`userSlice` 只定义了同步 reducers，异步操作（获取用户列表、创建/更新/删除用户、登录）全部内联在各页面中。与 `userSlice` 相比，`timesheetSlice` 也存在同样的问题。

**解决的问题：**
| 问题 | 之前 | 之后 |
|------|------|------|
| API 调用位置 | 各页面内联 | thunk 封装，页面只 dispatch |
| loading/error 管理 | 页面各自维护 | Redux 统一管理 |
| 错误处理 | 页面 catch | `rejectWithValue` 统一处理 |
| 重复 API 请求 | 详情页/编辑页各自请求同一用户 | 优先从 Redux 缓存读取 |
| 创建/更新后刷新 | 全量 `getUsers()` + `setUsers()` | thunk 自动更新 store |

**修改文件清单：**

| 文件 | 改动 |
|------|------|
| `src/store/userSlice.ts` | 新增 6 个 async thunks：`fetchUsers`、`fetchUserById`、`createUser`、`updateUser`、`removeUser`、`loginUser`；`extraReducers` 处理 pending/fulfilled/rejected |
| `src/pages/UserListPage.tsx` | `getUsers()` → `dispatch(fetchUsers())`；删除 → `dispatch(removeUser(id))` |
| `src/pages/UserDetailPage.tsx` | 优先从 `users.find()` 读取缓存，未命中则 `dispatch(fetchUserById(id))` |
| `src/pages/UserEditPage.tsx` | 同上缓存策略；提交 → `dispatch(updateUser({id, updates}))` |
| `src/pages/UserCreatePage.tsx` | 全量刷新 → `dispatch(createUser(data))` |
| `src/pages/LoginPage.tsx` | `loginApi` + `setCurrentUser` → `dispatch(loginUser(...)).unwrap()` + `dispatch(fetchUsers()).unwrap()` |
